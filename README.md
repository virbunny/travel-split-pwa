# 米兔分帳小幫手 V1.4.8

旅行用分帳 PWA。重點是「誰先付、誰分攤、最後誰轉給誰」，不是完整會計系統。

## V1.4.8 新增／修正

- 資料頁的「更新記錄」改為預設折疊，點開才顯示完整版本紀錄。
- 匯入「全部行程 JSON」前會先確認；確認後會覆蓋目前所有行程與資料。
- 匯入「單一行程 JSON」時，若偵測到同名或同 ID 行程，會讓使用者選擇：
  1. 覆蓋原行程；
  2. 另存副本；
  3. 取消匯入。
- 避免不小心匯入同名行程後，行程列表多出重複資料。

## V1.4.7 新增／修正

- 帳簿頁明細表新增「操作」欄。
- 可從「帳簿」分頁直接編輯單項支出或現金池出資紀錄。
- 不必先切回「記一筆」或「現金池」再從列表中尋找原紀錄。
- 帳簿頁的編輯按鈕會載入原資料到對應表單，修改後按「更新這一筆」或「更新現金池紀錄」。

## V1.4.6 新增／修正

- 若結算方式選「統一幣別」，HTML／列印輸出的「支出明細」金額也會同步換算成使用者指定幣別。
- 支出明細不再在統一結算狀態下只顯示原幣別金額，避免和結算摘要、類別統計混淆。
- 支出明細會以統一幣別金額為主，原始金額以小字括註，方便對帳。
- 若缺少某幣別匯率，該筆會標示「缺匯率」，並保留原金額。

## V1.4.5 新增／修正

- 類別統計會跟隨結算方式。
- 若選「原幣別分開」，類別統計維持各幣別分列。
- 若選「統一幣別」，類別統計會依使用者輸入的匯率換算成同一幣別，不再分幣別顯示。
- HTML／列印輸出的類別統計也同步採用同一規則。
- 若缺少匯率，會明確提示哪些幣別尚未納入統一類別統計。

## V1.4.3

- 結算頁新增「結算方式」：可選「原幣別分開」或「統一幣別」。
- 使用者可自選統一幣別：台幣、日圓、韓幣、美金。
- 使用者自行輸入匯率，格式為「1 原幣別 = 多少統一幣別」；本工具不查即時匯率。
- 統一幣別只影響結算摘要與列印／HTML 輸出，不改動原始支出紀錄。
- 複製結算文字會依目前結算方式輸出。



## V1.4.5 新增功能

- 新增「結算列印」獨立功能頁。
- 將結算摘要、每人收支、類別統計、列印單一行程、匯出單一行程 HTML、排序依據與列印範圍集中在同一頁。
- 結算列印頁可直接切換「原幣別分開／統一幣別」並設定匯率，設定與結算頁共用。
- 資料分頁回歸資料備份與更新記錄，不再分散放類別統計與列印設定。

## V1.4.2

- 新增「類別統計」，依目前行程彙總各類別花費總和。
- 類別統計以原幣別分開列出，不做匯率換算。
- HTML／列印輸出新增「類別統計」列印範圍選項。

## V1.4.1 完整原生部署版

這版是「不要再用 service worker 熱修補丁」的完整版本。主要功能直接寫在 `index.html` 主程式內：

- 既有支出可編輯，不只是刪除。
- 現金池紀錄可編輯。
- 雲端連結可編輯。
- 自訂分攤金額可用於同一筆帳單不同人不同金額。
- 首頁有「查看個人帳簿」捷徑。
- JSON 匯出後會提示 Android 常見存檔位置。
- `service-worker.js` 改為 V1.4.1 乾淨快取，不再注入修補功能。

### Android GitHub App 上傳重點

至少覆蓋這 4 個檔案：

1. `index.html`  ← 最重要，所有主功能都在這裡。
2. `service-worker.js`  ← 必須更新，否則手機可能繼續吃舊快取。
3. `manifest.webmanifest`
4. `README.md`

`icons/` 這版沒有變更，可以不用重傳。

上傳後請開 GitHub Pages 網頁重新整理一次，再關掉 PWA 重開。

## V1.1 新增功能

- 行程分帳：不同旅行可分開記錄，例如大邱三日行、廣島遊。
- 現金池：可記錄誰先放錢進共同錢包，支出可選現金池支付。
- 原幣別結算：台幣、日圓、韓幣、美金分開結算，不使用當日匯率。
- 雲端收據／票券連結：支出可附連結，也可另外建立連結庫。
- 日期搜尋：用日期下拉選單篩支出，也可再加關鍵字搜尋。
- JSON 備份：可匯出全部行程，也可只匯出目前行程。

## 使用方式

1. 開啟 `index.html` 測試。
2. 若要安裝成 PWA，請將整個資料夾放到 GitHub Pages、Netlify 或其他 HTTPS 網站。
3. 用手機瀏覽器開啟後，選擇「加到主畫面」。

## 注意

- 資料存在瀏覽器本機，清除瀏覽資料前請先匯出 JSON。
- 現金池各幣別分開，不會互相折算。
- 如果現金池支出超過已登錄出資，結算頁會提示補登。
