# 米兔分帳小幫手 V1.3.1

旅行用分帳 PWA。重點是「誰先付、誰分攤、最後誰轉給誰」，不是完整會計系統。

## V1.3.1 更新

- JSON 匯出完成後，顯示檔名與 Android 常見下載位置。
- 提醒使用者可在「檔案／Files → Download／下載」或「Chrome → ⋮ → 下載內容」查看。
- 補充說明：瀏覽器基於隱私限制，不會把完整實際路徑交給 PWA。

## V1.3.0 更新

- 既有紀錄可編輯。
- 支出、現金池、雲端連結可修改後再儲存，不必刪除重建。

## V1.2.9 更新

- 新增自訂分攤金額。
- 適合點餐各吃各的，例如總額 190，甲 100、乙 90，付款者甲。

## 主要功能

- 行程分帳：不同旅行可分開記錄，例如大邱三日行、廣島遊。
- 現金池：可記錄誰先放錢進共同錢包，支出可選現金池支付。
- 原幣別結算：台幣、日圓、韓幣、美金分開結算，不使用當日匯率。
- 雲端收據／票券連結：支出可附連結，也可另外建立連結庫。
- JSON 備份：可匯出全部行程或目前行程，也可匯入還原。
- 個人帳簿：可依旅伴與幣別查看個人支出、分攤與明細。
