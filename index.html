個人支出總覽

這頁當一般帳簿使用：看每個人在本行程中「自己先付多少、現金池出資多少、個人實際分攤消費多少」。它不是最後轉帳結算，最後誰付誰仍看「結算」分頁。

最後誰付誰

預設保留原幣別分開結算；若想看單一幣別總結，可改用「統一幣別結算」，並自行輸入本次行程採用匯率。
自行設定匯率：請輸入「1 原幣別 = 多少統一幣別」。例如統一成台幣時，可填 1 JPY = 0.22 TWD。本工具不查即時匯率，也不改動原始支出紀錄。

類別統計

依目前行程統計各類別花費總和；若結算方式選「統一幣別」，類別統計也會同步換算成同一幣別，避免混淆。

列印／HTML 輸出設定

輸出單一行程的清爽版 HTML，可直接列印或另存 PDF。版面改用深色大字，並可自行選擇列印範圍，避免兩天資料就印出十幾頁。

想省頁數：只勾「結算摘要＋類別統計＋支出明細」即可。若結算方式選「統一幣別」，支出明細金額也會同步換算。要完整留底，再加勾現金池、帳簿與雲端連結。

更新記錄

V1.4.7｜帳簿頁單項編輯
帳簿頁明細表新增「操作」欄，可直接從個人帳簿編輯相關支出或現金池出資紀錄，不必再回到費用列表尋找。
V1.4.6｜統一幣別支出明細
若結算方式選「統一幣別」，列印／HTML 輸出的支出明細金額也同步換算成統一幣別；原金額以小字括註，避免與結算摘要和類別統計混淆。
V1.4.5｜統一幣別類別統計
若結算方式選「統一幣別」，類別統計同步換算成使用者指定幣別，不再分幣別列出，避免與統一結算結果混淆。
V1.4.4｜結算列印中心
新增「結算列印」獨立功能頁，集中顯示結算摘要、每人收支、類別統計與列印／HTML 輸出設定，避免結算與分類散在不同分頁。
V1.4.3｜統一幣別結算
結算頁新增「原幣別分開／統一幣別」選項；使用者可自選統一幣別並自行輸入匯率，結算摘要與 HTML／列印輸出會依設定顯示。
V1.4.2｜類別統計
新增「類別統計」，依類別彙總各幣別花費總和；HTML／列印輸出可選擇是否包含類別統計。
V1.4.1｜HTML／列印輸出強化
新增單一行程 HTML 輸出、列印單一行程、排序依據與列印範圍選項；列印版改用深色大字，避免 PDF 字太小太淡，也能減少頁數。
V1.4.0｜完整原生部署版
把既有紀錄編輯、自訂分攤金額、帳簿捷徑、JSON 匯出位置提示與更新記錄全部整合在 index.html 主程式內，不再依賴 service worker 熱修補丁。
V1.3.1｜JSON 匯出位置提示
匯出 JSON 後會顯示檔名與 Android 常見下載位置，方便找備份檔。
V1.3.0｜既有紀錄可編輯
支出、現金池、雲端連結都新增「編輯」按鈕，可修改後更新，不必刪除重建。
V1.2.9｜自訂分攤金額
新增支出可選「自訂分攤金額」，適合點餐各吃各的；自訂金額合計需等於總金額。
V1.2.8｜首頁帳簿捷徑移到最上方
在「目前行程」下方直接新增「📒 查看個人帳簿」按鈕，避免手機畫面下方或頁面中段看不到；新增本更新記錄。
V1.2.7｜首頁帳簿捷徑
在首頁「目前行程設定」加入帳簿捷徑。
V1.2.6｜個人帳簿總覽
新增「帳簿」分頁，可依旅伴與幣別查看個人支出、分攤與明細。
V1.2.5｜行程名稱可編輯
行程列表可直接修改行程標題，不需刪除重建。
V1.2.4｜綠藍配色
移除粉紅點綴，改成淺綠主色＋粉藍輔色。

安裝與離線

部署到 GitHub Pages、Netlify 或任何 HTTPS 網站後，可用手機瀏覽器「加到主畫面」。開啟過一次後，之後可離線使用。

危險區

刪除前建議先匯出 JSON。
